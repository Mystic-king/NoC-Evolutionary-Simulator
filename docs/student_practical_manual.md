# Student Practical Manual

## How to submit an experiment

1. Open the Streamlit application or use the CLI.
2. Select the practical and set the requested parameters.
3. Record the random seed and all parameter values.
4. Execute the experiment.
5. Inspect the generated graphs and numerical outputs.
6. Download the experiment ZIP.
7. In your lab record, include aim, theory, algorithm, configuration, output, observations,
   limitations and your own conclusion.

Do not submit only a screenshot. Include the generated configuration and results.

## Practical 1 — Introduction to GEM5 and Garnet

**Aim:** Understand a 2D mesh NoC, packet traffic patterns and dimension-order XY routing,
then optionally execute a real GEM5/Garnet configuration.

**Python learning preview:** Creates a mesh, generates uniform, transpose, hotspot or
neighbor traffic, computes XY paths, and reports packet hop counts. These are educational
model results, not GEM5 statistics.

**Actual GEM5 mode:** Supply a compiled GEM5 executable and a Garnet-compatible Python
configuration script. The adapter records the exact command, stdout, stderr, return code,
and numeric values parsed from `stats.txt`.

**Study:** Routers, network interfaces, links, topology, routing, traffic injection,
latency, throughput and the distinction between a functional simulator and a simplified model.

## Practical 2 — Discrete NoC Routing Optimization using GA

**Aim:** Find a low-cost path between source and destination routers in a 2D mesh.

**Method:** Candidate chromosomes represent valid simple paths. The optimizer applies
elitist retention, parent selection, path crossover at a common intermediate router,
and mutation to another valid path. Fitness combines hop count, seeded synthetic
intermediate-router congestion and a small turn penalty.

**Outputs:** Best path, hop count, cost, convergence graph and mesh route image.

**Limitation:** Congestion is generated by a deterministic random seed. It is not sampled
from a real Garnet network. Use GEM5 statistics for simulator-based validation.

## Practical 3 — CNN Routing Path Prediction

**Aim:** Train a CNN to classify the next-hop direction in a mesh.

**Input channels:** Current-router one-hot map, destination-router one-hot map and a
synthetic congestion map.

**Labels:** East, west, south and north according to XY dimension-order routing.

**Outputs:** Trained PyTorch checkpoint, training/validation loss, validation accuracy,
confusion matrix and held-out predictions.

**Discussion:** Explain train/validation split, overfitting, class-wise errors and why
synthetic labels do not establish performance on a physical or measured NoC.

## Practical 4 — Nature-Inspired / Metaheuristic Algorithms

**Aim:** Compare Genetic Algorithm, Particle Swarm Optimization, Ant Colony Optimization
and Simulated Annealing on the same continuous Rastrigin minimization benchmark.

**Known optimum:** Zero at the all-zero vector.

**Outputs:** Best objective values, per-algorithm convergence plots and comparison CSV/PNG.

**Discussion:** Compare convergence speed, final objective, stochastic variability,
parameter sensitivity and computational cost. Repeat using multiple seeds.

## Practical 5 — Basic Genetic Algorithm

**Aim:** Maximize `f(x)=x²` for an unsigned binary integer represented by a chromosome.

**Operators:** Binary encoding, tournament selection, single-point crossover, bit-flip
mutation and elitism.

**Outputs:** Best chromosome, decoded integer, fitness, generation history and convergence plot.

**Discussion:** Compare the best result with the known optimum. This small search space
can also be exhaustively solved; GA is being used to teach the evolutionary process.

## Practical 6 — Neuro-Fuzzy System (ANFIS)

**Aim:** Approximate `sin(pi*x) * cos(pi*y)` over inputs in [-1,1].

**Model:** Two-input, four-rule first-order Sugeno ANFIS using Gaussian membership
functions. Consequent parameters are estimated with least squares; premise parameters
are adjusted using finite-difference gradient steps.

**Outputs:** Membership centers and widths, rule definitions, training history,
held-out predictions and validation RMSE.

**Discussion:** Explain fuzzy membership, rule firing strength, normalized firing,
consequent functions, hybrid learning and validation error.

## Practical 7 — Genetic Algorithm for TSP

**Aim:** Find a short closed tour that visits every generated city once and returns to start.

**Representation:** Permutation chromosome.

**Operators:** Tournament selection, order crossover, swap mutation and elitism.

**Outputs:** Best tour, Euclidean distance, route visualization and convergence history.

**Discussion:** Compare the heuristic route with a baseline nearest-neighbor route or
brute force for very small city counts. A GA does not guarantee the global optimum.
